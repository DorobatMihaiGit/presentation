# M0 Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the bare CV repo: a Next.js 16 app on pinned pnpm 11 / TypeScript 7 / Biome / Tailwind 4, typed env validation, EN/RO locale routing with real Vitest and Playwright tests, a local Postgres 18 container, Git LFS attributes, and a GitHub Actions CI. Cloud accounts (GitHub remote, Vercel, Neon) are set up by hand in a final manual checklist.

**Architecture:** One Next.js App Router app with a `src/` dir. `src/proxy.ts` (Next 16's new name for `middleware.ts`) runs next-intl's locale middleware. The only root layout is `src/app/[locale]/layout.tsx`, and it reads the locale through `next/root-params`. Env vars are checked by a pure factory (`src/lib/create-app-env.ts`), so tests don't need a real env. `src/env.ts` builds the app instance from it, and `next.config.ts` imports that, so a bad env fails `dev`, `build` and `start` right away. No database code yet (that starts in M2).

**Tech Stack:** Next.js 16.3.6 (Turbopack), React 19.3.0, TypeScript 7.0.2 (native `tsc`), Biome 2.5.14, Tailwind CSS 4.3.3, next-intl 4.14.6, zod 4.6.5, @t3-oss/env-nextjs 0.13.11, Vitest 5.0.1 + Vite 8.3.0, @playwright/test 1.63.0, pnpm 11.27.1 via Corepack, Docker `postgres:18-alpine`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-23-cinematic-cv-design.md` (sections 2, 3, 7 row M0, 8, 9)

export default getRequestConfig(async ({ locale }) => {

### Task 5: Git LFS attributes for media

**Files:**
- Create: `.gitattributes`

**Interfaces:**
- Consumes: nothing.
- Produces: an LFS filter on `public/seq/**`, `public/3d/**` and `*.blend`. `public/seq/**/manifest.json` stays plain text. M4's asset pipeline writes frames and manifests under these paths.

- [ ] **Step 1: Verify no attributes yet (red)**

Run: `git check-attr filter -- public/seq/s1/landscape/0001.avif`
Expected: `public/seq/s1/landscape/0001.avif: filter: unspecified`

- [ ] **Step 2: Create `.gitattributes`**

`!attr` resets manifests to "unspecified", so they diff and merge as ordinary text. (`-diff` would mark them binary instead.)

```gitattributes
# Binary media tracked with Git LFS (Vercel project must have Git LFS enabled).
public/seq/** filter=lfs diff=lfs merge=lfs -text
public/3d/** filter=lfs diff=lfs merge=lfs -text
*.blend filter=lfs diff=lfs merge=lfs -text

# Sequence manifests stay plain text so they diff in review and build without LFS.
public/seq/**/manifest.json !filter !diff !merge text
```

### Task 6: GitHub Actions CI and full local gate

**Files:**
- Create: `.github/workflows/ci.yml`

**Interfaces:**
- Consumes: scripts `typecheck`, `lint`, `test`, `build`, `test:e2e`; `packageManager`; `engines.node`. `DATABASE_URL` must be present at config load (Task 2).
- Produces: workflow `CI` with jobs `check` ("Typecheck, lint, unit, build") and `e2e` ("Playwright e2e"). It runs on pushes to `main`/`dev` and on all PRs.

- [ ] **Step 1: Create `.github/workflows/ci.yml`**

`DATABASE_URL` is set at workflow level because `next typegen`, `next build` and `next start` all load `next.config.ts`, which validates env. No database runs in CI during M0. The e2e job uses the Playwright image pinned by the spec, with `--user 1001` as Playwright's CI docs recommend. `checkout` leaves LFS off: there are no LFS objects yet, and M4 decides on LFS caching in CI.

```yaml
name: CI

on:
  push:
    branches: [main, dev]
  pull_request:

concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true

permissions:
  contents: read

env:
  DATABASE_URL: postgres://cv:cv@localhost:5432/cv
  NEXT_TELEMETRY_DISABLED: "1"

jobs:
  check:
    name: Typecheck, lint, unit, build
    runs-on: ubuntu-24.04
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@v7
      - uses: pnpm/action-setup@v6
      - uses: actions/setup-node@v7
        with:
          node-version-file: package.json
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm typecheck
      - run: pnpm lint
      - run: pnpm test
      - run: pnpm build

  e2e:
    name: Playwright e2e
    runs-on: ubuntu-24.04
    timeout-minutes: 20
    container:
      image: mcr.microsoft.com/playwright:v1.63.0-noble
      options: --user 1001
    steps:
      - uses: actions/checkout@v7
      - uses: pnpm/action-setup@v6
      - uses: actions/setup-node@v7
        with:
          node-version-file: package.json
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm test:e2e
      - if: failure()
        uses: actions/upload-artifact@v7
        with:
          name: playwright-report
          path: playwright-report/
          retention-days: 7
```
