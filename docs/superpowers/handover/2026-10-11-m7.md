## How to resume

1. Start **Docker Desktop** and wait for "Engine running". If it says it
   cannot start, run `wsl --shutdown` and start it again.
2. In the repo (Git Bash):

   ```bash
   export PATH="$PATH:/c/Program Files/Docker/Docker/resources/bin"
   export COREPACK_ENABLE_DOWNLOAD_PROMPT=0
   git switch feat/m7-look-and-projects && git pull
   docker compose up -d --wait
   ```

   `pnpm` is not installed globally: use `corepack pnpm <script>`.
3. Run the gate (about 35 minutes; keep the laptop on mains power). The
   clone must sit on a **short path** (a deep `node_modules` path over 260
   characters breaks Lighthouse's imports) and must be cloned with
   `core.autocrlf=false` (CRLF fails Biome and the poster hash):

   ```bash
   cat > /tmp/m7-gate.sh <<'EOF'
   #!/usr/bin/env bash
   set -e
   REPO="$1"; BRANCH="$2"; CI_DIR="$3"
   export PATH="$PATH:/c/Program Files/Docker/Docker/resources/bin" COREPACK_ENABLE_DOWNLOAD_PROMPT=0
   pnpm() { corepack pnpm "$@"; }
   docker compose -f "$REPO/docker-compose.yml" exec -T db dropdb -U cv --if-exists cv_gate
   docker compose -f "$REPO/docker-compose.yml" exec -T db createdb -U cv cv_gate
   git clone -q -c core.autocrlf=false --branch "$BRANCH" "$REPO" "$CI_DIR"
   cd "$CI_DIR"
   export CI=1 NEXT_TELEMETRY_DISABLED=1
   export DATABASE_URL=postgres://cv:cv@localhost:5432/cv_gate
   export ADMIN_EMAIL=ci-owner@example.com
   export BETTER_AUTH_SECRET="$(node -e 'console.log(require("crypto").randomBytes(32).toString("base64"))')"
   pnpm install --frozen-lockfile
   pnpm typecheck
   pnpm lint
   pnpm test
   pnpm db:migrate
   pnpm db:seed
   pnpm build
   pnpm test:e2e
   pnpm perf:local
   SITE_URL=http://localhost:3200 pnpm build
   pnpm lhci:windows
   echo "gate=0"
   EOF
   bash /tmp/m7-gate.sh "$PWD" feat/m7-look-and-projects "C:/Users/MiHAi/AppData/Local/Temp/m7gate" > /tmp/m7-gate.log 2>&1
   tail -1 /tmp/m7-gate.log   # expect gate=0
   ```

   Delete the clone afterwards from PowerShell (long paths):
   `cmd /c 'rd /s /q "\\?\C:\Users\MiHAi\AppData\Local\Temp\m7gate"'`.
   If `C:\Users\MiHAi\AppData\Local\Temp\m7gate` is still there from the
   stopped run, delete it the same way before starting.
4. With `gate=0`: open a pull request from `feat/m7-look-and-projects` into
   `dev`. CI (Ubuntu, original budgets, `pnpm lhci`) runs on the PR.
5. After the merge: enter the real EN/RO content in `/admin` (covers, case
   studies, links, the CV PDFs, the headshot) and look at `/en`, `/ro` and a
   project page.
